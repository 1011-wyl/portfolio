# NovelAI 作品集演示

入口：`/portfolio/novel-agent-demo/`。页面、布局、样式和交互组件来自 NovelAI `93de5d954ede9197d45054a690bd1eb4a58d8e95` 的 `apps/web/src/`，没有增加展示用 CSS 或改排页面。`npm run check:ui` 校验全部 60 个 Vue/CSS 文件；哈希见 `novel-demo-upstream.json`。

演示仅替换 API 数据层，使用 hash 路由适配 GitHub Pages，并在首次访问时选中有效的示例作品。原项目仍按原有方式开发和运行。

## 可以查看的页面

| 页面 | 入口与内容 |
| --- | --- |
| 我的小说 | 书架、搜索、排序、网格/列表、重命名、删除 |
| 创建小说 | 故事起点、创作偏好、连载计划三个步骤 |
| 创作工作台 | 方案审阅、编辑和版本比较，确认、暂停/继续、生成示例章节、储备与生产日志 |
| 作品阅读 | 章节切换、正文编辑与自动存草稿、版本历史、恢复草稿、应用修订、模拟助手、建议差异与批准/拒绝/回滚 |
| 长期记忆 | 重要人物档案、当前目标与关系、世界规则、时间线、虚构参考资料 |
| 仪表盘 | 写作热力图与趋势、LLM 统计、调用明细、项目/模型/状态/日期筛选、排序与分页 |
| 系统设置 | 偏好保存、原模型配置抽屉、模拟测试连接、保存/停用/清除配置 |

作品缺失和未知地址也保留原项目的提示页。移动端沿用原导航抽屉、章节目录和 AI 助手入口。

## 示例作品与操作

- **雾岛来信**：默认作品，三个约两千字的完整章节，人物、世界规则、时间线、资料与助手示例会话。可直接从左侧切换工作台、阅读和记忆。
- **雾岛来信 · 修订练习**：包含待修改的开篇。在工作台展开该章的“处理”菜单，可查看审校意见、重写、预览开篇修复，或接受当前版本；阅读页提供重新送审。开篇修复会保留本地快照，支持回退。
- **沿海慢信**：待确认的创作方案。可修改方案、生成新版本、对比及恢复，再确认并生成示例章节。
- 还可用“新建小说”走完三个步骤，自行创建不同作品；每本的正文、草稿、会话和版本独立。

正式正文只会在应用修订或完成审核后更新；批准助手建议先写入草稿。提交较早章节的修订会重置后续章节，可回工作台重新生成演示文本。

## 数据范围

所有作品、人物、章节、写作与调用统计均为演示样本，不代表真实用户、模型效果或真实调用量。研究资料为明确标注的虚构故事资料。生成、重写和助手回复使用本地固定文本，不调用外部模型或发布平台。

修改保存在当前浏览器的 `novel-agent-portfolio-demo-v2` 中，刷新后可继续。模型配置仅保存服务名称、地址、模型和开关；输入的 API Key 不保存、不发送。连接测试返回明确的本地模拟结果。存储不可用时，演示仍可在当前页面会话中运行。

要恢复初始示例，可在浏览器站点数据中删除该键，再刷新页面。书架视图、最近选择和阅读偏好继续使用原界面的浏览器设置。

## 维护与发布

在 `novel-agent-demo-src/` 中依次运行 `npm ci`、`npm run check:ui`、`npm test`、`npm run build`；构建输出为 `public/novel-agent-demo/`。然后在作品集根目录构建整个站点。GitHub Pages 工作流执行同一过程，包括所有动态页面分块，避免只更新两张截图或遗漏后续页面。
